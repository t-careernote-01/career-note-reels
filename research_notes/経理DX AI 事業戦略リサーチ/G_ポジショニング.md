## 1. キャリアノートの視聴者と経理DXの需要は重なるか／新チャンネルにするか、今のチャンネルを広げるか

### Takeaway
「経理への転職」「AI時代の経理キャリア」には、30歳前後の会社員の不安と重なる需要がある（経理担当者の8割以上がキャリアを考えたことがある、求人ではAI・自動化スキルが評価される、など）。ただ、キャリアノートは扱う範囲を「転職活動の前の土台づくり」に絞ると本人が決めている（2026-10-18）。そのうえ YouTube 側の考え方は「同じ視聴者なら同じチャンネル、違う視聴者なら別チャンネル」なので、**経理の実務やAI実務は別のチャンネル・別ブランドにし、キャリアノートとは「経理という職種の選び方」の回でゆるくつなぐ**のが筋が良い。

### Cited Findings
- 【YouTube公式側の考え方】YouTube Creator Liaison の Rene Ritchie は「The algorithm follows the audience, so please the audience（アルゴリズムは視聴者についていく。だから視聴者を喜ばせて）」と述べ、アナリティクスの「視聴者」タブで、どの動画が視聴者を増やしているかを見るよう勧めている — [Tubefilter (2024-08-26)](https://www.tubefilter.com/2024/08/26/rene-ritchie-shorts-creator-faqs/)
- 【同上・未検証】Ritchie は YouTube 公式ブログの「Rene's Top Five」で「同じ視聴者に響くと思うなら、同じチャンネルで試して」と答えた、と検索結果に出た。ただし、どの回の記事かは特定できていない。Think Media のポッドキャストを要約した第三者のまとめにも「same audience, same channel／different audience, different channel」とある — [Recapio（第三者による要約）](https://recapio.com/digest/youtube-employee-reveals-how-to-grow-your-channel-by-think-media-podcast)、関連：[YouTube Official Blog: Rene's Top Five (2024-05-30)](https://blog.youtube/creator-and-artist-stories/renes-top-five-on-youtube-may-30-2024-edition/)
- 【2つ目のチャンネル】vidIQ は、複数のチャンネルを運営すると負担が大きいと注意している。2つ目のチャンネルは、メインと重ならないニッチを選びつつ、ブランド全体とのつながりは保つ必要があるとしている — [vidIQ "Should You Start a Second YouTube Channel?"](https://vidiq.com/blog/post/should-you-start-a-second-youtube-channel)
- 【経理担当者のキャリア不安】マネーフォワードとCPAラーニングの資料では、経理担当者1,100名の調査で8割以上が「将来のキャリアを考えたことがある」と答えた。資格・スキル・環境の3軸で市場価値を上げる方法を扱っている — [マネーフォワード クラウド（ウェビナー資料ページ）](https://biz.moneyforward.com/library/69998/)
- 【経理の求人】doda は、2026年下半期（7〜12月）の経理職の求人は全体として増える見込みとし、背景にシェアードサービス・BPO・アウトソーシング企業の採用拡大を挙げている。評価されやすいスキルには生成AIと自動化を挙げ、AIで入力を効率化するだけでなく、**AIの出力を検証・改善できる力**が求められるとしている — [doda 経理職の転職市場予測](https://doda.jp/guide/market/007_1.html)
- 【米国の参考値】会計職の求人のうち、AIスキルを要件に含むものの割合は2025年の18%から2026年は30%に上がった（Datarails の調査）。FP&A職は43%、コントローラー職は24% — [Ohio CPA (2026-04-03)](https://ohiocpa.com/get-involved/news/2026/04/03/study--accounting-jobs-requiring-ai-skills-increase-by-67)
- 【経理キャリアの動画は企業系が中心】CPAラーニングのチャンネルには「経理部をざっくり５種類に分けてみた！【経理のキャリア】」などのキャリア系の動画がある — [YouTube](https://www.youtube.com/watch?v=CLnpIJyhbrQ)
- 【キャリア動画全体の競争】キャリア映像メディア「PIVOT CAREER」は2026年7月に開設し、7月28日に登録者10万人を超えたと発表した。資本力のあるメディアがキャリアの分野に入ってきている — [Web担当者Forum（PR TIMES転載）](https://webtan.impress.co.jp/r/prtimes/items/000000048.000083417)
- 【乗り換えた・2つ目のチャンネルを持つ人の例】個人の発信者が、キャリア系から経理系へ乗り換えた例や、2つ目のチャンネルを運営している具体例は、今回の検索では見つからなかった（Gapsを参照）。

### Inferences
- 重なる部分は「経理という職種に向いているか（自己分析）」「AI時代に経理を選んで大丈夫か（不安）」の2点。これは「転職活動の前の土台づくり」に入れられるので、キャリアノートで**単発の回**として扱える（例：数字に苦手意識がない人は経理を選択肢に入れていい？／経理に向く『動詞』）。一方で「経理への転職のしかた」「求人の選び方」は、本人が決めた範囲の外になる。
- 経理DX・AIの実務（仕訳、月次、AIで照合）の視聴者は「今まさに経理をしている人」や「社長」で、キャリアノートの「迷っている30歳前後」とは**別の視聴者**。Ritchie の考え方に照らすと、別チャンネルにするのが自然。
- おすすめの形：キャリアノートはそのまま続ける。経理DXは**別の名前のチャンネル（例：「タクマ｜経理ノート」のように『ノート』というブランドで揃える）**にする。キャリアノートの経理職の回の概要欄や終了画面から誘導して、ゆるくつなぐ。2つ目のチャンネルの負担（vidIQ の注意点）は、今のスライド＋ナレーションの制作手順と make_slides.py を使い回して抑える。
- 本業がある会社員で、時間に限りがある。最初の3〜6か月は、経理DXを**note・X・テンプレート配布で需要を確かめ**、反応があったテーマだけを長尺の動画にする、という順番の方が負担が少ない。

### Gaps
- 個人の発信者がキャリア系から経理・会計系へ乗り換えた例や、メインのほかにニッチな2つ目のチャンネルを持つ例は、日本語の事例を特定できなかった。YouTube Data API で調べる必要がある（youtube-research スキル）。
- 「チャンネルのテーマを揃えると推薦に有利か」を数字で示した公式データは見つからなかった。公式の考え方は、上の「視聴者についていく」という説明にとどまる。
- doda とマネーフォワードの原文は開けなかった（ネットワークの制約）。数値は検索結果の要約からとっている。

## 2. 差別化の軸ごとの需要と競合

### Takeaway
需要がはっきりしているのは「中小企業のバックオフィスDX（人材不足・何から始めればいいかわからない）」と「ひとり経理（中小企業の過半数は経理担当が1人）」。競合が強いのは、税理士・会計士・会計ソフトのベンダーが占めている「税務・制度の解説」と「ツールのセミナー」。タクマの経歴で無理なく名乗れるのは**「市役所の税務→会計事務所→経理と、税・会計の現場を回ってきた非エンジニアの会社員が、複雑なことを整理して1対1の目線で説明する」**こと。「元税務職員の視点」は守秘義務のため、話せる中身が限られる。

### Cited Findings
- 【ひとり経理の需要】中小企業庁の「平成26年度 中小企業における会計の実態調査」を紹介する資料では、経理担当者が「1人」と答えた企業が58.2%だった（2014年度で古い） — [中小企業庁関連資料（検索結果）](https://www.chusho.meti.go.jp/zaimu/kaikei/2011/download/0823kaikei_enquete-1.pdf)、[マネーフォワード ブログ](https://biz.moneyforward.com/blog/25755/)
- 【経理担当者の困りごと】ミロク情報サービスの調査（有効回答362件）では、課題として最も多かったのは「伝票の作成・帳簿の記入・仕訳入力」。次に経費精算、給与計算が続く。回答者はMJSの読者などに偏っている — [MJS プレスリリースPDF](https://www.mjs.co.jp/news/news_2024/000000391.000018493/pdf/d18493-391-21203061fcc596d08223d13f252979be.pdf)
- 【社長向けのバックオフィスDX】中小企業でDXが進まない理由は「社内にIT人材がいない」36.3%、「何から始めればよいかわからない」21.3%、「コストの余裕がない」20.9% — [DXマガジン](https://dxmagazine.jp/news/2605ukre13/)
- 帝国データバンクの調査では、約9割がDXの必要性を認めている一方で、成果が出ているのは約2割。最大の壁は推進できる人材の不足 — [ニュースイッチ](https://newswitch.jp/p/35534)
- 中小機構の調査では、DXに取り組んでいる・検討している企業は31.2%、取り組む予定がない企業は37.2%。課題は「DXに関わる人材が足りない」が31.1%で最多 — [J-Net21](https://j-net21.smrj.go.jp/news/hgc8pd000001r3go.html)
- 【経理のAI活用】LayerX の調査（経理・財務の474名、2024年8〜9月）では、AIを使ったシステムを導入している経理部門は24.3% — [AIsmiley](https://aismiley.co.jp/ai_news/bukuraku-layerx-airesearch/)
- BOXIL の調査（AIを使っている78人）では、最も多い用途は書類・文章の記入ミスや漏れのチェック。78人中59人が「効率が上がった」と答えた — [BOXIL Magazine](https://boxil.jp/mag/a10659/)
- 【競合：ベンダーのセミナー】バクラク（LayerX）は「AIで経理業務を最適化する」セミナーを毎月のように開いている — [バクラク セミナー 2026-11](https://bakuraku.jp/seminar/whole_261104_261119/)、[同 2026-10](https://bakuraku.jp/seminar/whole_261002_261013/)
- 【競合：資格を持つ人のチャンネル】まとめ記事で紹介されている会計・経理系のチャンネル：オタク会計士ch（公認会計士 山田真哉、登録者約111万〜115万人と記事によって違う）、税理士YouTuberチャンネル（ヒロ税理士）、税理士 河南、経理実務の学校（ジャスネット運営、実務動画200本以上）、CPAラーニング — [弥生 会計士がおすすめするチャンネル](https://media.yayoi-kk.co.jp/10729/)、[経理実務の学校](https://www.youtube.com/channel/UCP3PSQ2OuR40ZGXvCsJ2o1Q)、[クロスメディアン note](https://note.com/crossmedian/n/n26017582bbda)、[マネーポスト](https://www.moneypost.jp/735007)
- 【税理士の発信の考え方】見込み客を集めるためにYouTubeをする税理士は、登録者が増えすぎると対象外の人が集まって、本当に来てほしい客が埋もれると述べている（数より質を重視） — [Google Docs 記事](https://docs.google.com/document/d/1G-3scc5tUixTlrKpcQ37W_hdjZ3u3WALKeqiMkTfvuI/export?format=pdf)

### Inferences
- 主軸は**「AI実務特化（非エンジニア・中小企業の経理担当向け）」に「経理×キャリア」を組み合わせる**形がよい。AIを使うことそのものより、「AIの出力をどう確かめるか」「どの業務から任せるか」を整理して見せる方が、doda が挙げる評価スキルとも、本人の強み（複雑なことを整理して伝える）とも合う。
- 「ひとり経理」は、テーマ（チャンネルの中のシリーズ）としては有力。ただ「元ひとり経理」とは名乗れないので、「ひとり経理の人が最初にAIに任せる3つの業務」のように**視聴者を指す言葉**として使う。
- 「税務署目線」は避ける。市役所の税務で働いた4年間は事実なので「役所の税務窓口側から見た、書類のどこで止まりやすいか」のような一般論に限れば使えるが、具体的な事例は話さない（3章・5章）。
- 社長向けは、会計事務所で経営者と関わった経験を足がかりに、1対1の相談の延長として後から足すのが現実的。

- 各軸の YouTube 検索ボリュームや競合動画の再生数は、APIで調べていない（youtube-research で確かめる必要がある）。
- 「ひとり経理」「経理×AI」で発信している個人のX・noteのアカウント名・フォロワー数は特定できなかった。

## 3. 信頼につながる要素（資格・実務年数・現役であること・実績）と、足りないものの補い方

### Takeaway
経理の分野で客観的に通じるのは「簿記2級以上」で、求人の応募条件として広く使われている。一方、YouTube の上位は公認会計士・税理士・企業のスクールが占めている。タクマの資格は**資料に記載がない**（持っているかどうか不明）。今使える信頼の材料は「税・会計の現場を3つ経験した（市役所の税務4年、会計事務所、経理の会社）」「今も現役で働いている」の2つ。足りないもの（資格・数字の実績・顔）は、「実際に作ったテンプレート・手順を見せる」「検証の過程を見せる」ことで補うのが妥当。

### Cited Findings
- 経理職の求人では、応募条件に簿記2級以上を掲げる企業が多く、体系的な知識を客観的に証明するものとされる（成果報酬型の広告を含むサイト） — [CREX転職](https://crexgroup.com/ja/tenshoku/?p=10554)
- 30代前半と後半では、転職市場での評価や企業が求めるものが違う（前半はポテンシャルや学習意欲を見られやすい） — [マイビジョン](https://my-vision.co.jp/consultant/inexperienced/30s)
- 簿記3級もない経理未経験の人が、何社も落ちた末に税理士事務所に採用された体験談がある — [リベシティ ライブラリ](https://library.libecity.com/articles/01JVF3HPK400D6ZP6MS8PB4V58)
- 会計系チャンネルで紹介されているのは、公認会計士（山田真哉）、税理士（ヒロ税理士、河南）、企業が運営するスクール（ジャスネット、CPAラーニング＝元上場企業の経理担当が講師）が中心 — [弥生](https://media.yayoi-kk.co.jp/10729/)、[ゆーちゅらランキング CPAラーニング動画](https://yutura.net/channel/83873/video/7DjmkzLtcPU/)
- 経理でAIを使う際の注意として「AIの分析結果をそのまま正しいとせず、総勘定元帳や証憑、加工前後の件数や金額を人が確かめる」ことが勧められている — [OBC ACField](https://www.obc.co.jp/acfield/list/post058?hs_amp=true)
- 視聴者が何を信頼すると言っているか（コメントや口コミ）を直接集めた一次資料は見つからなかった。

### Inferences
- 足りない可能性があるもの：①資格（簿記・税理士科目・IT資格）があるか不明、②数字の実績（チャンネルの決まりで使わないことになっている）、③エンジニアの経歴、④大勢の前での講演の実績。
- 補い方（経歴を盛らずにできること）：
  - **簿記2級を取る過程を発信する**（持っていないなら）：「スキルが積み上がるとやる気が出る」という強みと合い、資格そのものが信頼につながる。持っているなら、プロフィールに書くだけで効果がある。※持っているかどうかは本人に確かめる。
  - **「作ったものを見せる」**：AIへの指示文、確認用のチェックリスト、Excelのテンプレートを、架空の数字で実際に動かして見せる。数字の実績の代わりに「再現できること」を信頼の材料にする。
  - **確かめる過程を見せる**：OBC や doda が言う「AIの出力を検証する」手順そのものを中身にする。資格を持つ人のチャンネルとも差がつく。
  - **経歴は「税・会計の現場を3つ回った」とまとめる**：市役所の税務（地方税）、会計事務所、経理の会社。今も現役であることは、ツールの更新が早いAI実務では強みになる。
- 「元税務職員」と書くと国税の職員と誤解されるおそれがあるので、「元市役所の税務担当」と正確に書く方がよい。

### Gaps
- 視聴者・読者が経理系の発信者の何を信頼しているかを示す声（知恵袋・Xのリプライ・YouTubeのコメント）は集めていない。pain-research スキルで別途集める必要がある。
- タクマの資格の有無は資料にない（本人に確かめる）。

## 5. 経理の会社に勤めている制約（副業規定、利益相反、匿名・顔出しなし）

### Takeaway
副業を認める会社は増えている（制度がある企業72.5%など、調査によって11.8〜72.5%と大きく違う）。ただ、本業が経理の会社なので、**同じ業務の相談を受けたりテンプレートを売ったりすると、競業・利益相反に当たるおそれ**がある。就業規則を確かめ、必要なら届け出るのが先。さらに、市役所の税務だったころに知った納税者の情報には、退職後も守秘義務がある。顔出しなし・本名なしでの運営は今のキャリアノートと同じ形なので続けやすいが、会社名や取引先がわかる話はしないことが前提になる。

### Cited Findings
- 副業を認める企業の割合は、調査によって大きく違う：マイナビ「中途採用実態調査2025」は72.5%（制度がある）、東京商工リサーチは「積極的に認めている」11.78%、エンは49%（容認）、パーソル総合研究所は64.3%（容認）、経団連（2022）は70.6% — [マイナビ キャリアリサーチLab](https://career-research.mynavi.jp/reserch/20250930_101865/)、[マイナビニュース](https://news.mynavi.jp/article/20251029-3600318/)、[労務ドットコム](https://roumu.com/archives/category/main/%E5%83%8D%E3%81%8D%E6%96%B9%E6%94%B9%E9%9D%A9/%E5%89%AF%E6%A5%AD%E5%85%BC%E6%A5%AD)
- 正社員で実際に副業をしている人は11.0%で過去最高（20代男性は20.2%） — [マイナビ キャリアリサーチLab](https://career-research.mynavi.jp/?p=101865)
- 厚生労働省の「副業・兼業の促進に関するガイドライン」関連資料では、副業を制限できる場合として、秘密が漏れる場合、競業により会社の利益を害する場合などを挙げている（PDF。今回は中身を開いていない） — [厚生労働省PDF](https://www.mhlw.go.jp/content/11201250/000638936.pdf)
- 地方公務員法34条は「職員は、職務上知り得た秘密を漏らしてはならない。その職を退いた後も、また、同様とする」と定め、違反すると刑事罰（地公法60条）がある — [弁護士ドットコム](https://www.bengo4.com/c_5/c_1629/c_1730/bbs/%E5%9C%B0%E6%96%B9%E5%85%AC%E5%8B%99%E5%93%A1+%E5%AE%88%E7%A7%98%E7%BE%A9%E5%8B%99/)、[早稲田大学リポジトリ 論文](https://waseda.repo.nii.ac.jp/record/8447/files/A03890546-00-063030001.pdf)
- 地方税の職員には、地方税法22条に別の守秘義務もある（検索結果では条文を確かめられなかった。要確認）。
- 顔を出さない・匿名で運営している経理系の個人YouTuberの具体例は、今回の検索では特定できなかった。

### Inferences
- 発信する前に確かめること：①就業規則の副業規定（許可制か届出制か）、②競業避止の範囲（経理の会社なら、記帳代行・経理代行・経理コンサルが本業と重なる可能性が高い）、③会社の顧客から相談されたり、顧客に売ったりしないこと、④会社のツールや資料を持ち出さないこと。
- 利益相反を避けやすい中身：**個人の経理担当者向けの学び・キャリア・AIの使い方（教育コンテンツ）**。避けた方がよいもの：代行・受託・社長向けの有料コンサル（本業と競合しうる）。社長向けの1対1相談は、規定を確かめてからにする。
- 匿名・顔出しなしの運用：今の「タクマ」の名前とスライド＋声の形でそのまま始められる。架空の会社・架空の数字を使っている、とはっきり言う。会社名・業種・取引先がわかる細部は出さない。
- 「元税務職員の視点」は、守秘義務があるので「制度の一般論」と「書類が止まりやすい一般的な傾向」に限る。具体的な納税者の事例や、役所の内部の運用は話さない。

### Gaps
- タクマの会社の就業規則は不明（本人に確かめる）。
- 厚労省のガイドラインと地方税法22条は、原文の該当部分を確かめていない。
- 経理系で顔を出さない・匿名の個人の発信者（YouTube・X）の具体名と規模は特定できなかった。YouTube Data API や X での検索で追加調査が必要。
