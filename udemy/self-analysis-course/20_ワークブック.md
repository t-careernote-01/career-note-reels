# 自己分析ワークブック｜5つの枠で、自分に合う働き方を1文にする

（Udemy講座「自己分析ワーク」付属。PDF版・スプレッドシート版の元原稿）

---

## このワークブックの使い方

**最後に手元に残るもの**
- 5つの枠（苦手・価値観・力が出る環境・強み・生活の土台）を埋めた1枚
- 「自分に合う働き方」の1文
- 今週やる小さな一歩1つ

**3つの約束**
1. **白紙から考えなくていい。** どのシートも、一覧から○をつけるところから始めます
2. **全部やらなくていい。** ★のついたステップだけやれば、次のシートに進めます。★だけなら1シート5〜15分です
3. **深掘りしなくていい。** 思い出すのは最近の小さな出来事で十分です。書いていてつらくなったら、そのステップは飛ばしてください

**記号**
- ★ … 最短ルート。ここだけやれば次に進める
- ⏸ … 今日はここまででOKの区切り
- 🆘 … 止まったら見る欄（質問・迷ったときの決め方・AIプロンプト）

**進め方の例**
- まとめてやる：休日に、★だけなら2時間半〜3時間、全部やると3時間半ほど（動画約85分＋ワーク）
- 少しずつやる：平日に1日20〜30分（動画＋★のワーク）で、8日

| 日 | 見る動画 | やるワーク（★だけ） | 目安 |
|---|---|---|---|
| 1日目 | 1-1〜1-4（14分） | ワーク0 | 20分 |
| 2日目 | 2-1〜2-3（12分） | ワーク1 | 25分 |
| 3日目 | 3-1〜3-2（7分） | ワーク2 | 20分 |
| 4日目 | 4-1〜4-2（7分） | ワーク3 | 20分 |
| 5日目 | 5-1〜5-4（16分） | ワーク4 | 30分 |
| 6日目 | 6-1〜6-2（6分） | ワーク5 | 15分 |
| 7日目 | 7-1〜7-2（8分） | ワーク6 | 20分 |
| 8日目 | 8-1〜9-3（15分） | ワーク7 | 25分 |

シフト勤務の人は「日」を「休みの日」と読みかえてください。間が空いても、続きから始めれば大丈夫です。

**イヤだったことを書くのがつらい人へ**
今の職場がしんどい人や、思い出すとつらくなる人は、次の順で進めてください。
1. ワーク1は、一覧に○をつけるだけにする（場面は書かない）。1-Bは飛ばし、1-Cは○をつけた項目を「避けたい」「工夫すればできる」に分けるだけでいい
2. 先にワーク3（力が出る環境）をやる（動画は4-1・4-2を先に見てかまいません）
3. ワーク2（価値観）は、一覧から「あったらうれしいもの」を直接選ぶ
4. そのあとは、ワーク4から順に進める
それでもつらいときは、ワークより休むことを先にしてください。眠れない・食べられない状態が続くときは、医療機関や公的な相談窓口（厚生労働省の「こころの耳」など）に相談してください。この講座はカウンセリングの代わりにはなりません。

**記入例の3人（すべて架空の人物です）**

| | ミカさん | ケンタさん | アヤさん |
|---|---|---|---|
| 年齢 | 29歳 | 32歳 | 27歳 |
| 仕事 | メーカーの営業事務（6年目） | 食品メーカーの法人営業（9年目） | アパレル店の副店長（5年目） |
| 今の気持ち | 不満は大きくない。でも、この仕事をあと30年続ける姿が想像できない | 成績は悪くない。でも、毎月数字に追われる生活に疲れてきた | 接客は好き。でも、この働き方を長く続けられる気がしない |

## ワーク0｜最初の5分（レクチャー1-3）

**ねらい**：思い出す練習です。正解はありません。1行ずつで十分です。

**よくある例（近いものがあれば、それをきっかけに）**
- イヤだったこと：会議が長引いた／急ぎの依頼が入った／同じ説明を何度もした／休憩が取れなかった
- ほっとしたこと：予定どおりに終わった／「ありがとう」と言われた／うまく説明できた／静かに作業できた
- 頼まれたこと：やり方を聞かれた／資料を見てほしいと言われた／代わりに電話に出た／相談に乗った

★ **最近1週間の仕事で、次の3つを1行ずつ書いてください。**

| 質問 | あなたの1行 |
|---|---|
| ① ちょっとイヤだったこと | |
| ② ちょっとほっとしたこと・うれしかったこと | |
| ③ 人に頼まれたこと（小さなことでいい） | |

**記入例**
- ミカさん：①課長からの急ぎの依頼で、午前の予定が全部ずれた ②作った資料を「見やすい」と言われた ③新人さんに経費精算のやり方を聞かれた
- ケンタさん：①月末の数字の確認で、上司に3回同じことを聞かれた ②取引先の担当者が「相談してよかった」と言ってくれた ③後輩の見積もりを見てほしいと頼まれた
- アヤさん：①休憩が取れないまま7時間立ちっぱなしだった ②横について教えた新人スタッフが、一人で売れるようになった ③新人スタッフに、たたみ方をもう一度教えてほしいと言われた

🆘 **止まったら**
- 1週間で思い出せなければ「今日」か「昨日」でかまいません
- 手帳・カレンダー・チャットの履歴を見ると思い出しやすいです
- ①〜③のうち1つしか書けなくても、次に進んでください
- ①を書くのがつらいときは、①は空けて②と③だけで大丈夫です

🆘 **AIを使うなら（コピペ用）**
```
最近1週間の仕事を思い出したいです。
「ちょっとイヤだったこと」「ちょっとほっとしたこと」「人に頼まれたこと」の順に、私に1回に1問ずつ質問してください。
答えや分析は出さないでください。3問終わったら、私の答えを3行で並べて終わりにしてください。
```

ここで書いた3行は、このあとのワークの材料になります。

## ワーク1｜苦手：イヤだったことを細かく分ける（セクション2）

**ねらい**：「〇〇が苦手」をそのまま仕事選びに使うと、選べる仕事が減ります。イヤだったことを細かく分けて、**本当に避けたい条件**だけを残します。

### 1-A ★ イヤだった場面に○をつける（レクチャー2-1）

今の仕事・前の仕事・アルバイトで「イヤだった」「しんどかった」場面に○をつけてください。いくつでもかまいません。

**何を（作業の中身）**
- □ 同じ作業をひたすら繰り返す
- □ 細かい数字やミスのチェックが続く
- □ 正解がない企画やアイデアを求められる
- □ 人前で発表・プレゼンをする
- □ 電話やメールの対応で作業が何度も止まる
- □ 知らない人に営業や声かけをする
- □ 体を使う作業・立ち仕事が長い
- □ 書類やルールを覚えることが多い
- □ 夜間・休日の呼び出しや緊急対応がある

**誰と（人との関わり方）**
- □ 大人数の会議や飲み会
- □ 怒っている人・クレームの対応
- □ 一人きりで誰とも話さない時間が長い
- □ 細かく指示される・見張られる
- □ 指示があいまいで、何を求められているか分からない
- □ 人の機嫌に合わせて動く
- □ 社内の調整・根回しが多い
- □ 競争や比べられることが多い
- □ きつい言い方をする人がいる
- □ 陰口や派閥がある
- □ 困ったときに相談できる人がいない

**どう進める（ペース・ルール・決め方）**
- □ 急な予定変更・割り込みが多い
- □ 自分で決められず、毎回確認が必要
- □ 逆に、何でも自分で決めないといけない
- □ 締め切りが短く、いつも追われる
- □ やり方が決まっていて変えられない
- □ 結果が数字だけで評価される
- □ 何をしても評価が見えない
- □ 長期間、成果が出るまで待つ

**どんな状況で（量・時間・場所・プレッシャー）**
- □ 残業や休日出勤が多い
- □ シフトや勤務時間が不規則
- □ 通勤が長い
- □ 騒がしい・人の出入りが多い場所
- □ 失敗が許されない緊張が続く
- □ 責任が重いのに、権限がない
- □ 仕事量が多すぎて終わりが見えない
- □ 逆に、仕事が少なくて退屈

- 上にないもの：（　　　　　　　　　　　　　　　）

★ **○をつけた中から、特にイヤだったものを3つまで選んで、そのときの場面を1行で書いてください。**
（書くのがつらいものは、場面を書かずに○だけでかまいません）

| 選んだもの | そのときの場面（1行） |
|---|---|
| | |
| | |
| | |

**記入例**
- ミカさん：「急な予定変更・割り込みが多い」→ 課長からの急ぎの依頼で、午前の予定が全部ずれた／「電話やメールの対応で作業が何度も止まる」→ 月末の請求書作成中に電話が10回以上鳴った／「何をしても評価が見えない」→ 6年同じ仕事で、誰の役に立っているのか分からない
- ケンタさん：「結果が数字だけで評価される」→ 取引先に喜ばれた提案も、売上が小さいと評価されなかった／「知らない人に営業や声かけをする」→ 新規開拓の電話を1日50件かけた時期がつらかった／「締め切りが短く、いつも追われる」→ 毎月1日に数字がリセットされる
- アヤさん：「体を使う作業・立ち仕事が長い」→ 休憩なしで7時間立ちっぱなし／「シフトや勤務時間が不規則」→ 前の日に翌週のシフトが決まり、友達と予定が合わない／「怒っている人・クレームの対応」→ 店長がいない日に、一人で30分謝り続けた

🆘 **止まったら**
- ワーク0の①に書いた「ちょっとイヤだったこと」が、一覧のどれに近いかを探すところから始めてください
- ○が1つしかつかなくても大丈夫です。1つあれば次に進めます
- 特定の人がイヤだったときは、その人の名前ではなく「どんな関わり方がイヤだったか」に置きかえてください。「高圧的な先輩」なら「相談しにくい上下関係」です
- 小さなことでかまいません。「毎朝の会議が長い」くらいで十分です

⏸ 今日はここまででもOKです。

### 1-B 「〇〇が苦手」を細かく分ける（レクチャー2-2）

1-Aで選んだ3つのうち1つを選んで、「イヤだったのは、どの部分か」を探します。

★ **まず1問だけ答えてください。**
「その場面で、もし1つだけ変えられたら、何を変える？」
→ 答え：（　　　　　　　　　　　　　　　　）
変えたいところが、本当にイヤだった部分です。★はここまでです。

**記入例（ミカさん：「急な予定変更・割り込みが多い」）**
1つだけ変えるなら → 急ぎの依頼を、午後にまとめてもらう
→ イヤだったのは依頼そのものではなく、**自分の作業が何度も途中で止まること**

**時間がある人は、4つの切り口でも分けてみてください。**

| 切り口 | 質問 | あなたの答え |
|---|---|---|
| 何を | 作業そのものがイヤだった？ | |
| 誰と | 相手や人数がイヤだった？ | |
| どう進める | ペースや決め方がイヤだった？ | |
| どんな状況で | 量・時間・場所・緊張がイヤだった？ | |

**記入例（ケンタさん：「知らない人に営業や声かけをする」）**
| 切り口 | 答え |
|---|---|
| 何を | 話すこと自体はイヤではない。商品の説明も嫌いではない |
| 誰と | 知らない相手に断られ続けるのがつらい。知っている取引先なら平気 |
| どう進める | 1日50件という数のノルマがイヤだった |
| どんな状況で | 断られ続けて、夕方には気持ちが削れていた |

→ 苦手なのは「営業」ではなく、**「関係のない相手に、数のノルマで断られ続けること」**だった

**記入例（アヤさん：「怒っている人・クレームの対応」）**
→ 苦手なのは「接客」ではなく、**「責任者がいない中で、一人でクレームを受け続けること」**だった

🆘 **止まったら**
- 4つ全部埋まらなくていいです。1つ「ここだ」と分かれば十分です
- 「イヤではない」という答えも、立派な1行です。イヤではない部分が分かると、選べる仕事が減りません

🆘 **AIを使うなら（コピペ用）**
```
私が仕事で苦手だと感じたことを細かく分けたいです。
苦手なこと：「（ここに1つ書く）」
「何を・誰と・どう進める・どんな状況で」の4つの切り口で、私に1回に1問ずつ質問してください。
答えや分析は出さず、質問だけしてください。4問終わったら、私の答えを短く並べて終わりにしてください。
```

### 1-C ★ 「避けたい」と「工夫すればできる」に分ける（レクチャー2-3）

1-Aと1-Bで出てきた苦手を、2つに分けてください。

| どうしても避けたい（仕事選びの条件にする） | 工夫すればできる（条件にしない） |
|---|---|
| | |
| | |

**迷ったらこれ（2つの質問）**
1. 「もう一度仕事を選び直せるとしたら、それがある仕事を選ぶか？」→ 選ばない＝避けたい／それがあっても選ぶ＝工夫すればできる
   （「今まで耐えてこられた」ことと「これからも続けたい」は別です。耐えられるかではなく、選ぶかで決めます）
2. 「人や職場が変わったら、平気になりそうか？」→ 平気になりそう＝仕事の中身ではなく、今の職場の問題です。避けたい欄には「〇〇な職場」と書きます（例：相談しにくい上下関係の職場）

**記入例**
- ミカさん：避けたい＝1日中割り込みが続いて、自分の作業が進まない状況／工夫すればできる＝電話対応そのもの（時間が決まっていれば平気）
- ケンタさん：避けたい＝関係のない相手に、数のノルマで断られ続けること／工夫すればできる＝新規の営業（紹介や既存の取引先からなら平気）
- アヤさん：避けたい＝休憩のない長時間の立ち仕事、前の週まで決まらないシフト／工夫すればできる＝クレーム対応（責任者が近くにいれば平気）

🆘 **止まったら**
- 全部が「避けたい」に入ったときは、2つ目の質問を当ててください。今の職場が変われば平気なものは、「〇〇な職場」とまとめて1つにします
- 全部が「工夫すればできる」に入ったときは、それでかまいません。「避けたい」が空でも、次に進めます

## ワーク2｜価値観：イヤだったことの裏返し（セクション3）

**ねらい**：価値観は「仕事を選ぶときに譲れない判断基準」です。いきなり「大事にしたいことは？」と聞かれると止まります。イヤだったことを裏返すと、大事にしたいことが見えてきます。

### 2-A ★ 裏返して、言葉を選ぶ（レクチャー3-1）

ワーク1-Aで書いた3つの場面（○だけの人は○をつけた項目）を1つずつ裏返して、下の一覧から近い言葉を選んでください。3行まででかまいません。
（イヤだったことを書くのがつらい人は、裏返さなくて大丈夫です。一覧から「あったらうれしいもの」に直接○をつけてください）
裏返しのほかに、ワーク0の②「うれしかったこと」から選んでもかまいません。

| イヤだったこと | 裏返すと（本当はどうしたかった？） | 一覧から選んだ言葉 |
|---|---|---|
| | | |
| | | |
| | | |

**価値観の言葉の一覧（近いものに○）**

| 安心・安定 | 成長・挑戦 | 人との関係 | 自分らしさ | 貢献・意味 |
|---|---|---|---|---|
| □ 見通しが立つ | □ スキルが積み上がる | □ 信頼できる仲間 | □ 自分のペースで進める | □ 誰かの役に立つ |
| □ 収入が安定している | □ 新しいことを覚える | □ 感謝される | □ 自分で決められる | □ 人に喜ばれる |
| □ 生活リズムが整う | □ 難しいことに挑戦する | □ 長く付き合える関係 | □ 工夫できる余地がある | □ 社会に意味がある |
| □ 落ち着いた環境 | □ 成果が目に見える | □ 公平に扱われる | □ 得意なことを活かせる | □ 納得できるものを勧める |
| □ 無理なく続けられる | □ 認められる・評価される | □ 一人で集中できる | □ 好きなことに関われる | □ 誰かの成長を支える |
| □ 休みがきちんと取れる | □ 専門性が身につく | □ チームで協力する | □ 正直でいられる | □ 丁寧な仕事ができる |
| □ 家族との時間 | □ 責任ある仕事を任される | □ 上下関係がゆるやか | □ 変化や刺激がある | □ 正確な仕事ができる |
| □ 健康を守れる | □ 自分の力を試せる | □ 相談できる人がいる | □ 自由な時間がある | □ 結果が誰かに届く |

**裏返しの例**
- 急な予定変更が多い → 見通しが立つ
- 数字だけで評価される → 公平に扱われる／納得できるものを勧める
- 誰の役に立っているか分からない → 結果が誰かに届く／誰かの役に立つ
- 細かく見張られる → 自分で決められる
- シフトが不規則 → 生活リズムが整う

**記入例**
- ミカさん：急な予定変更が多い→見通しが立つ／誰の役に立っているか分からない→結果が誰かに届く／電話で作業が何度も止まる→一人で集中できる
- ケンタさん：新規の相手に断られ続ける→長く付き合える関係／数字だけで評価される→納得できるものを勧める／毎月リセットされる→スキルが積み上がる
- アヤさん：シフトが不規則→生活リズムが整う／責任者がいない中で、一人でクレームを受け続けた→相談できる人がいる／（うれしかったこと）新人が一人で売れるようになった→誰かの成長を支える

⏸ 今日はここまででもOKです。

### 2-B ★ 3つに絞る（レクチャー3-2）

選んだ言葉が4つ以上あれば、3つに絞ってください。

**絞り方**：2つずつ比べて、「どちらか1つしか守れないなら、どっち？」と聞きます。残ったものが上位です。

**迷ったらこれ**：「これが欠けたら、ほかがよくても辞めたくなるもの」を残します。

| 順位 | 価値観 | それが守られていた場面（1行。なければ空欄でいい） |
|---|---|---|
| 1 | | |
| 2 | | |

- □ 職種名ではなく、「何をする」「どんな環境で」が入っている
- □ 避けたいこと（苦手）か、守りたいこと（生活の土台）が1つ以上入っている

🆘 **止まったら**
- 空欄の枠があっても、埋まっている枠だけで1文を作ってください。あとから足せます
- 長すぎると感じたら、「強み」と「苦手」だけで先に作ってみてください。「〔強み〕を活かせて、〔苦手〕が少ない仕事」
- 苦手の欄が空の人は、「〔強み〕仕事を、〔力が出る環境〕で。〔生活の土台〕は守る。」だけで完成です

🆘 **AIを使うなら（コピペ用）**
```
自分に合う働き方を1文にしたいです。私の5つの答えを書きます。
強み：（　）／価値観：（　）／力が出る環境：（　）／苦手：（　）／生活の土台：（　）
この5つの言葉をできるだけそのまま使って、「〜仕事を、〜で。〜は避けて、〜は守る。」の形で、言い回しの違う案を3つ出してください。
新しい要素や職種名は足さないでください。
```

## ワーク7｜今の仕事の点検と、今週の一歩（セクション8）

### 7-A ★ 今の仕事を5つの枠で点検する（レクチャー8-1）｜約5分

今の仕事が、5つの枠をどれくらい満たしているかを付けます。深く考えず、最初に浮かんだ印でかまいません。
○＝満たしている　△＝少し足りない　×＝足りない

| 枠 | 今の仕事 | ひとこと |
|---|---|---|
| 強みが使えている | | |
| 価値観が守られている | | |
| 力が出る環境がある | | |
| 苦手（避けたい条件）が少ない | | |
| 生活の土台が守れている | | |

**記入例（ミカさん）**
| 枠 | 付け | ひとこと |
|---|---|---|
| 強み | △ | 手順書づくりは年に数回だけ |
| 価値観 | × | 見通しが立たない日が多い |
| 環境 | △ | 作業は任されているが、割り込みが多い |
| 苦手 | × | 1日中、電話と急ぎの依頼で中断される |
| 土台 | ○ | 残業は月15時間くらい |

🆘 **止まったら**
- 付けられない枠は、空けたまま進んでください
- ○か△かで迷ったら△にします。あとで直せます

⏸ 今日はここまででもOKです。

### 7-B ★ 3つの道から選んで、今週の一歩を決める（レクチャー8-2）｜約5分

×と△をよくするために、次の3つの道から、今いちばん試しやすいものを選んでください。辞めるか残るかを、今決める必要はありません。

| 道 | こんなときに | 今週の一歩の例 |
|---|---|---|
| A 今の場所で調整する | 仕事そのものは嫌いではなく、△や×の原因が、やり方や担当の範囲にある | 上司に相談したいことを3行のメモにする／自分でできる工夫を1つ試す |
| B 役割や部署を変える | 会社は合っているが、今の担当が合わない | 社内で、1文に合いそうな部署や役割を1つ調べる／その仕事をしている人に15分話を聞く |
| C 外を調べ始める | 生活の土台が×／今の職場の人間関係や体制が原因で、社内では変えにくい／×が多くて、A・Bでは変わりそうにない | 同じ仕事を別の職場でする場合と、別の仕事をする場合のどちらかで、1文に合いそうな職場を1つ調べる（付録4の表を使う） |

**選び方の目安**
- 上の「こんなときに」は目安です。×の数より、**自分が試せそうかどうか**で選んでください
- 辞めたくない人は、×が多くてもAかBから試してかまいません
- 生活の土台が×のときは、体や生活を守ることを先に考えてください。一歩の例：今週、残業しない日を1日決める／休みの希望を出す／信頼できる人に、今の働き方がつらいと話す。眠れない・食べられない状態が続くときは、使い方ページの相談窓口へ
- 迷ったら、いちばん小さくて今週中に終わるものを選びます

**上司に伝える3行メモの型（Aを選んだ人向け）**
1. 今の仕事で、もっとやりたいこと（強みが使える仕事）
2. 困っていること（×の枠の、具体的な場面1つ）
3. 相談したいこと（「〇〇を試してみてもいいですか」の形）

**今週の一歩（1つだけ）**
- 選んだ道：（A・B・C）
- 一歩：（　　　　　　　　　　　　　　　）
- いつやる：（　　月　　日）

**記入例**
- ミカさん：A ─ 「手順書・マニュアル整備をもっと担当したい」と上司に伝えるメモを3行書く。金曜の面談で話す
- ケンタさん：B ─ 社内の既存取引先担当のチームで働く先輩に、15分話を聞く。水曜の昼休みに声をかける
- アヤさん：C ─ 店舗スタッフを教える「トレーナー」という仕事がどんな1日を過ごすのか、その仕事をしている人の紹介記事を1本読んで、付録4の表に当てる。日曜の夜に

大きな決断は、一歩やってみたあとで十分です。

**ひとつだけ覚えておいてほしいこと**
条件をそろえるだけでは、合う働き方にはなりません。**自分の強みで、誰かの役に立てる場所**かどうかも一緒に見てください。ワーク4-Cの「誰の、何に役立つか」が、その目印です。

## 付録1｜AIを使うときの2つの注意

1. **AIの答えをそのまま採用しない。** 自分の出来事が入っていない言葉は、それらしく見えても、しっくりきません。AIには質問してもらう、言い換えてもらう、だけにします
2. **会社名・人の実名・社外秘の情報は入れない。** 「取引先」「上司」「Aさん」のように書き換えてください

どのAIでも使えます（ChatGPT・Claude・Gemini など）。AIを使わなくても、このワークブックは最後まで終わります。

## 付録2｜診断の結果が手元にある人へ

ストレングスファインダーや性格診断の結果がある人は、こう使ってください。
1. 結果の言葉に、○（当たっている）・△（少し）・×（違う）を付ける
2. ○の言葉について、「それが出た出来事」を1つ書く。書けなければ、その言葉は使わない
3. 出来事が書けた言葉だけを、ワーク4-Aの動詞選びの参考にする。ワーク2の価値観、ワーク3の条件の言葉を選ぶときの参考にしてもかまいません

**例（エンジニアの人）**：診断の「収集心」に○ → 出来事：障害の原因を調べて、手順にまとめた → 動詞：調べる・まとめる

診断の言葉は、出来事とつながったときにだけ使えます。

## 付録4｜1文を使って職場を見るときの表

調べるときや、話を聞くときに、1文のどこを確かめればいいかの目安です。求人票の読み方や応募の手順ではありません。「合いそうかどうか」を見るための表です。

| 1文の部分 | 確かめること | 調べ方の例 |
|---|---|---|
| 強み（何をする仕事か） | 1日の仕事の中で、その動詞をどれくらい使うか | 仕事内容の説明、その仕事をしている人の話 |
| 価値観 | 大事にしたいことが守られていそうか | 評価のされ方、会社や部署が大事にしていること |
| 力が出る環境 | 人数・進め方・任され方 | チームの人数、1人で進めるか分担か |
| 苦手（避けたい条件） | 避けたい条件が毎日ありそうか | 1日の流れ、繁忙期の様子 |
| 生活の土台 | 削れない線が守れそうか | その職場で働く人の話、会社の仕事紹介 |

分からないところは「？」のままでかまいません。「？」が多い場所は、人に話を聞くと分かることが多いです。

## 付録5｜仕事別の言葉のヒント

記入例の3人と仕事が違う人は、一覧にない言葉を「上にないもの」に足すときの参考にしてください。

- IT・エンジニア：仕様が決まらない／手戻りが多い／夜間の障害対応／一人で集中できる／やり方を任される／在宅勤務
- 介護・医療：夜勤の回数／人手が足りない／申し送りがきつい／利用者さん・患者さんに感謝される／チームで支え合える
- 接客・販売・飲食：立ち仕事の長さ／シフトの決まり方／クレーム対応／お客さんの反応がすぐ分かる
- 製造・物流：体力の負担／決まった手順／安全への緊張／段取りを工夫できる
- 事務・総務：割り込み／締め切りの重なり／仕組みを整える／社内の人に頼られる
