# 自己分析ワークブック｜5つの枠で、自分に合う働き方を1文にする

（Udemy講座「自己分析ワーク」付属。PDF版・スプレッドシート版の元原稿）

---

## このワークブックの使い方

**最後に手元に残るもの**
- 5つの枠（苦手・価値観・力が出る環境・強み・生活の土台）を埋めた1枚
- 「自分に合う働き方」の1文
- 今週やる小さな一歩1つ

**3つの約束**
1. **白紙から考えなくていい。** どのシートも、一覧から○をつけるところから始めます
2. **全部やらなくていい。** ★のついたステップだけやれば、次のシートに進めます。★だけなら1シート10分です
3. **深掘りしなくていい。** 思い出すのは最近の小さな出来事で十分です。書いていてつらくなったら、そのステップは飛ばしてください

**記号**
- ★ … 最短ルート。ここだけやれば次に進める
- ⏸ … 今日はここまででOKの区切り
- 🆘 … 止まったら見る欄（質問・迷ったときの決め方・AIプロンプト）

**進め方の例**
- まとめてやる：休日に2〜3時間
- 少しずつやる：平日に1日1シート（10〜15分）で、8日

**記入例の3人（すべて架空の人物です）**

| | ミカさん | ケンタさん | アヤさん |
|---|---|---|---|
| 年齢 | 29歳 | 32歳 | 27歳 |
| 仕事 | メーカーの営業事務（6年目） | 食品メーカーの法人営業（9年目） | アパレル店の副店長（5年目） |
| 今の気持ち | 不満は大きくない。でも、この仕事をあと30年続ける姿が想像できない | 成績は悪くない。でも、毎月数字に追われる生活に疲れてきた | 接客は好き。でも、この働き方を長く続けられる気がしない |

## ワーク0｜最初の5分（レクチャー1-3）

**ねらい**：思い出す練習です。正解はありません。1行ずつで十分です。

★ **最近1週間の仕事で、次の3つを1行ずつ書いてください。**

| 質問 | あなたの1行 |
|---|---|
| ① ちょっとイヤだったこと | |
| ② ちょっとほっとしたこと・うれしかったこと | |
| ③ 人に頼まれたこと（小さなことでいい） | |

**記入例**
- ミカさん：①課長からの急ぎの依頼で、午前の予定が全部ずれた ②作った資料を「見やすい」と言われた ③新人さんに経費精算のやり方を聞かれた
- ケンタさん：①月末の数字の確認で、上司に3回同じことを聞かれた ②取引先の担当者が「相談してよかった」と言ってくれた ③後輩の見積もりを見てほしいと頼まれた
- アヤさん：①休憩が取れないまま7時間立ちっぱなしだった ②迷っていたお客さんに合う服が見つかって、喜んでもらえた ③新人スタッフに、たたみ方をもう一度教えてほしいと言われた

🆘 **止まったら**
- 1週間で思い出せなければ「今日」か「昨日」でかまいません
- 手帳・カレンダー・チャットの履歴を見ると思い出しやすいです
- ①〜③のうち1つしか書けなくても、次に進んでください

ここで書いた3行は、このあとのワークの材料になります。

## ワーク1｜苦手：イヤだったことを細かく分ける（セクション2）

**ねらい**：「〇〇が苦手」をそのまま仕事選びに使うと、選べる仕事が減ります。イヤだったことを細かく分けて、**本当に避けたい条件**だけを残します。

### 1-A ★ イヤだった場面に○をつける（レクチャー2-1）

今の仕事・前の仕事・アルバイトで「イヤだった」「しんどかった」場面に○をつけてください。いくつでもかまいません。

**何を（作業の中身）**
- □ 同じ作業をひたすら繰り返す
- □ 細かい数字やミスのチェックが続く
- □ 正解がない企画やアイデアを求められる
- □ 人前で発表・プレゼンをする
- □ 電話やメールの対応で作業が何度も止まる
- □ 知らない人に営業や声かけをする
- □ 体を使う作業・立ち仕事が長い
- □ 書類やルールを覚えることが多い

**誰と（人との関わり方）**
- □ 大人数の会議や飲み会
- □ 怒っている人・クレームの対応
- □ 一人きりで誰とも話さない時間が長い
- □ 細かく指示される・見張られる
- □ 指示があいまいで、何を求められているか分からない
- □ 人の機嫌に合わせて動く
- □ 社内の調整・根回しが多い
- □ 競争や比べられることが多い

**どう進める（ペース・ルール・決め方）**
- □ 急な予定変更・割り込みが多い
- □ 自分で決められず、毎回確認が必要
- □ 逆に、何でも自分で決めないといけない
- □ 締め切りが短く、いつも追われる
- □ やり方が決まっていて変えられない
- □ 結果が数字だけで評価される
- □ 何をしても評価が見えない
- □ 長期間、成果が出るまで待つ

**どんな状況で（量・時間・場所・プレッシャー）**
- □ 残業や休日出勤が多い
- □ シフトや勤務時間が不規則
- □ 通勤が長い
- □ 騒がしい・人の出入りが多い場所
- □ 失敗が許されない緊張が続く
- □ 責任が重いのに、権限がない
- □ 仕事量が多すぎて終わりが見えない
- □ 逆に、仕事が少なくて退屈

- 上にないもの：（　　　　　　　　　　　　　　　）

★ **○をつけた中から、特にイヤだったものを3つまで選んで、そのときの場面を1行で書いてください。**

| 選んだもの | そのときの場面（1行） |
|---|---|
| | |
| | |
| | |

**記入例**
- ミカさん：「急な予定変更・割り込みが多い」→ 課長の急ぎの依頼で、午前の予定が全部ずれた／「電話やメールの対応で作業が何度も止まる」→ 月末の請求書作成中に電話が10回以上鳴った／「何をしても評価が見えない」→ 6年同じ仕事で、誰の役に立っているのか分からない
- ケンタさん：「結果が数字だけで評価される」→ 取引先に喜ばれた提案も、売上が小さいと評価されなかった／「知らない人に営業や声かけをする」→ 新規開拓の電話を1日50件かけた時期がつらかった／「締め切りが短く、いつも追われる」→ 毎月1日に数字がリセットされる
- アヤさん：「体を使う作業・立ち仕事が長い」→ 休憩なしで7時間立ちっぱなし／「シフトや勤務時間が不規則」→ 前の日に翌週のシフトが決まり、友達と予定が合わない／「怒っている人・クレームの対応」→ 店長がいない日に、一人で30分謝り続けた

⏸ 今日はここまででもOKです。

### 1-B 「〇〇が苦手」を4つに分ける（レクチャー2-2）

1-Aで選んだ3つのうち1つを選んで、4つの切り口で細かくしてください。「イヤだったのは、どの部分か」を探します。

| 切り口 | 質問 | あなたの答え |
|---|---|---|
| 何を | 作業そのものがイヤだった？ | |
| 誰と | 相手や人数がイヤだった？ | |
| どう進める | ペースや決め方がイヤだった？ | |
| どんな状況で | 量・時間・場所・緊張がイヤだった？ | |

**記入例（ケンタさん：「知らない人に営業や声かけをする」）**
| 切り口 | 答え |
|---|---|
| 何を | 話すこと自体はイヤではない。商品の説明も嫌いではない |
| 誰と | 知らない相手に断られ続けるのがつらい。知っている取引先なら平気 |
| どう進める | 1日50件という数のノルマがイヤだった |
| どんな状況で | 断られ続けて、夕方には気持ちが削れていた |

→ 苦手なのは「営業」ではなく、**「関係のない相手に、数のノルマで断られ続けること」**だった

**記入例（アヤさん：「怒っている人・クレームの対応」）**
→ 苦手なのは「接客」ではなく、**「責任者がいない中で、一人でクレームを受け続けること」**だった

🆘 **止まったら**
- 「その場面で、もし1つだけ変えられたら、何を変える？」と自分に聞いてください。変えたいところが、本当にイヤだった部分です
- 4つ全部埋まらなくていいです。1つ「ここだ」と分かれば十分です

### 1-C ★ 「避けたい」と「工夫すればできる」に分ける（レクチャー2-3）

1-Aと1-Bで出てきた苦手を、2つに分けてください。

| どうしても避けたい（仕事選びの条件にする） | 工夫すればできる（条件にしない） |
|---|---|
| | |
| | |

**迷ったらこれ**：「それが毎日続いたら、半年で辞めたくなるか？」→ はい＝避けたい／いいえ＝工夫すればできる

**記入例**
- ミカさん：避けたい＝1日中割り込みが続いて、自分の作業が進まない状況／工夫すればできる＝電話対応そのもの（時間が決まっていれば平気）
- ケンタさん：避けたい＝関係のない相手に、数のノルマで断られ続けること／工夫すればできる＝新規の営業（紹介や既存の取引先からなら平気）
- アヤさん：避けたい＝休憩のない長時間の立ち仕事、前の週まで決まらないシフト／工夫すればできる＝クレーム対応（責任者が近くにいれば平気）

🆘 **AIを使うなら（コピペ用）**
```
私が仕事で苦手だと感じたことを細かく分けたいです。
苦手なこと：「（ここに1つ書く）」
「何を・誰と・どう進める・どんな状況で」の4つの切り口で、私に1回に1問ずつ質問してください。
答えや分析は出さず、質問だけしてください。4問終わったら、私の答えを短く並べてください。
```

## ワーク2｜価値観：イヤだったことの裏返し（セクション3）

**ねらい**：価値観は「仕事を選ぶときに譲れない判断基準」です。いきなり「大事にしたいことは？」と聞かれると止まります。イヤだったことを裏返すと、大事にしたいことが見えてきます。

### 2-A ★ 裏返して、言葉を選ぶ（レクチャー3-1）

ワーク1で書いた「イヤだったこと」を1つずつ裏返して、下の一覧から近い言葉を選んでください。

| イヤだったこと | 裏返すと（本当はどうしたかった？） | 一覧から選んだ言葉 |
|---|---|---|
| | | |
| | | |
| | | |

**価値観の言葉の一覧（近いものに○）**

| 安心・安定 | 成長・挑戦 | 人との関係 | 自分らしさ | 貢献・意味 |
|---|---|---|---|---|
| □ 見通しが立つ | □ スキルが積み上がる | □ 信頼できる仲間 | □ 自分のペースで進める | □ 誰かの役に立つ |
| □ 収入が安定している | □ 新しいことを覚える | □ 感謝される | □ 自分で決められる | □ 人に喜ばれる |
| □ 生活リズムが整う | □ 難しいことに挑戦する | □ 長く付き合える関係 | □ 工夫できる余地がある | □ 社会に意味がある |
| □ 落ち着いた環境 | □ 成果が目に見える | □ 公平に扱われる | □ 得意なことを活かせる | □ 納得できるものを勧める |
| □ 無理なく続けられる | □ 認められる・評価される | □ 一人で集中できる | □ 好きなことに関われる | □ 誰かの成長を支える |
| □ 休みがきちんと取れる | □ 専門性が身につく | □ チームで協力する | □ 正直でいられる | □ 丁寧な仕事ができる |
| □ 家族との時間 | □ 責任ある仕事を任される | □ 上下関係がゆるやか | □ 変化や刺激がある | □ 正確な仕事ができる |
| □ 健康を守れる | □ 自分の力を試せる | □ 相談できる人がいる | □ 自由な時間がある | □ 結果が誰かに届く |

**裏返しの例**
- 急な予定変更が多い → 見通しが立つ
- 数字だけで評価される → 公平に扱われる／納得できるものを勧める
- 誰の役に立っているか分からない → 結果が誰かに届く／誰かの役に立つ
- 細かく見張られる → 自分で決められる
- シフトが不規則 → 生活リズムが整う

**記入例**
- ミカさん：見通しが立つ／結果が誰かに届く／正確な仕事ができる
- ケンタさん：長く付き合える関係／納得できるものを勧める／スキルが積み上がる
- アヤさん：生活リズムが整う／誰かの成長を支える／人に喜ばれる

⏸ 今日はここまででもOKです。

### 2-B ★ 3つに絞る（レクチャー3-2）

選んだ言葉が4つ以上あれば、3つに絞ってください。

**絞り方**：2つずつ比べて、「どちらか1つしか守れないなら、どっち？」と聞きます。残ったものが上位です。

**迷ったらこれ**：「これが欠けたら、ほかがよくても辞めたくなるもの」を残します。

| 順位 | 価値観 | それが守られていた場面（1行。なければ空欄でいい） |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

**記入例（ミカさん）**
1. 見通しが立つ ─ 繁忙期でも、前の週に予定が分かっていた月は落ち着いて働けた
2. 結果が誰かに届く ─ 手順書を作ったとき、新人さんが「助かった」と言ってくれた
3. 正確な仕事ができる ─ （空欄）

🆘 **止まったら**
- 言葉が1つも選べないときは、「イヤだったこと」の数を増やしてください。ワーク1の一覧に戻って○を足すだけでいいです
- 3つ選べなくても大丈夫です。1つあれば次に進めます

🆘 **AIを使うなら（コピペ用）**
```
仕事でイヤだったことを3つ書きます。
（1）（2）（3）
それぞれを裏返して「本当はどうしたかったか」を、私に1回に1問ずつ質問してください。
価値観の言葉をあなたが決めないでください。質問だけしてください。
```

## ワーク3｜力が出る環境（セクション4）

**ねらい**：同じ仕事でも、環境によって力が出たり止まったりします。力が出た場面から「条件」だけを取り出します。苦手と同じ4つの切り口を使います。

### 3-A ★ 力が出た場面を書く（レクチャー4-1）

次の質問から答えやすいものを1つか2つ選んで、場面を1行で書いてください。昔のことでなくていいです。最近1年の仕事から探してください。

- 時間を忘れて取り組んでいた作業は？
- 「疲れたけど、いい疲れだった」と感じた日は？
- いつもより仕事が早く進んだのは、どんなとき？
- ワーク0で書いた「ほっとしたこと・うれしかったこと」の場面は？
- 誰かに「ありがとう」と言われたのは、何をしたとき？

| 力が出た場面（1行） |
|---|
| |
| |

**記入例**
- ミカさん：新人さん向けに経費精算の手順書を作ったら、質問がほとんど来なくなった
- ケンタさん：取引先の売り場の困りごとを聞いて、並べ方を一緒に考えたら、発注が増えて担当者に喜ばれた
- アヤさん：新人スタッフに横について接客を教えたら、その子が一人で売れるようになった

### 3-B ★ 場面から条件を取り出す（レクチャー4-2）

3-Aの場面を、4つの切り口で見て、**そのとき何がそろっていたか**を書きます。○をつけるだけでもかまいません。

| 切り口 | 条件の例（近いものに○） | あなたの条件 |
|---|---|---|
| 何を | □ 形に残るものを作る □ 人に教える・説明する □ 困りごとを解決する □ 整理する・まとめる □ 体を動かす □ 考えて工夫する | |
| 誰と | □ 1対1 □ 少人数のチーム □ 一人で集中 □ 長く付き合う相手 □ 初めて会う人 □ 年下・後輩 | |
| どう進める | □ 自分のペースで □ やり方を任される □ 手順が決まっている □ 終わりが見える □ 相談できる人がいる □ 結果がすぐ分かる | |
| どんな状況で | □ 静かな場所 □ にぎやかな場所 □ 時間に余裕がある □ ほどよい締め切り □ 座ってできる □ 外に出られる | |

★ **条件を1文にまとめます。**
「私は、〔　　　　　　　　〕のとき、力が出る。」

**記入例**
- ミカさん：私は、**自分のペースで、終わりの見える作業を任されて、使ってくれる人がいる**とき、力が出る
- ケンタさん：私は、**長く付き合う相手と、時間をかけて困りごとを一緒に考えられる**とき、力が出る
- アヤさん：私は、**1対1で、相手ができるようになる様子が見える**とき、力が出る

**苦手と並べてみる**：ワーク1の「避けたい」と、ここの「力が出る」は、たいてい裏表になっています。
- ケンタさん：避けたい＝関係のない相手に数のノルマで断られ続ける／力が出る＝長く付き合う相手と時間をかけて考える

🆘 **止まったら**
- 力が出た場面が思い出せないときは、「イヤだったこと」の逆の状況を想像してください。「割り込みが多くてイヤだった」なら「割り込みがない日」はどうだったか
- 仕事で見つからなければ、趣味・家事・学生時代でもかまいません

🆘 **AIを使うなら（コピペ用）**
```
仕事で力が出た場面を1つ書きます。「（場面を1行）」
そのとき何がそろっていたのかを知りたいです。
「何を・誰と・どう進める・どんな状況で」の4つについて、私に1回に1問ずつ質問してください。
最後に、私の答えだけを使って「私は〜のとき力が出る」の形で1文にしてください。
```

## ワーク4｜強み：出来事と動詞で見つける（セクション5）

**ねらい**：「強みなんてない」と感じる人は、強みに名前をつけようとして止まっています。ここでは名前をつけません。**ここまでのワークで出てきた出来事**から、動詞を拾います。

**3つの言葉の違い（レクチャー5-1）**
- 好き：やっていて気持ちが上がること（気持ちの話）
- 得意：人より楽にできること（自分では当たり前すぎて気づきにくい）
- 強み：得意を、誰かの役に立つ場面で使えたもの

### 4-A ★ 出来事から動詞を拾う（レクチャー5-2）

ワーク0の③、ワーク2-Bの場面、ワーク3-Aの場面から、出来事を1〜3つ選んでください。その出来事で**自分がしたこと**を、下の動詞の一覧から選びます。

| 出来事（ここまでのワークから写す） | そのとき自分がしたこと（動詞を2〜3個） |
|---|---|
| | |

## ワーク5｜生活の土台（セクション6）

**ねらい**：好きな仕事、得意な仕事でも、お金・時間・体力が足りないと長く続きません。働き方を選ぶときの**削れない線**を決めます。

### 5-A ★ チェック項目に○をつける（レクチャー6-1）

自分にとって大事なものに○をつけてください。

**お金**
- □ 今の手取りから下げられない
- □ 少し下がっても、ほかの条件がよければいい
- □ 貯金を増やしたい・将来の大きな出費がある
- □ 家族の生活費を支えている

**時間**
- □ 残業は少なめがいい（月　　時間まで）
- □ 土日は休みたい
- □ 平日の夜に自分の時間がほしい
- □ 勤務時間は決まっているほうがいい
- □ 通勤は片道　　分まで

**体力**
- □ 立ち仕事・体を使う仕事は長時間はつらい
- □ 夜勤・不規則な勤務は避けたい
- □ 出張や移動が多いのはつらい
- □ 睡眠時間はしっかり取りたい
- □ 気を張り続ける仕事は疲れが残る

⏸ 今日はここまででもOKです。

### 5-B ★ 削れない線を決める（レクチャー6-2）

○をつけた中から、**「これが守れないなら、ほかがよくても続かない」**ものを、お金・時間・体力から1つずつ選んで書いてください。数字が入れられるものは数字で書きます。

| | 削れない線 |
|---|---|
| お金 | |
| 時間 | |
| 体力 | |

**記入例**
- ミカさん：お金＝今の手取りから大きく下げない／時間＝残業は月20時間まで。平日夜の習い事を続けたい／体力＝特になし（空欄）
- ケンタさん：お金＝来年子どもが生まれるので、今の年収は下げられない／時間＝土日は家族と過ごしたい／体力＝出張は月2回まで
- アヤさん：お金＝一人暮らしを続けられる額／時間＝前の月にはシフトが決まっていてほしい／体力＝立ちっぱなしは1日6時間くらいまで

**迷ったらこれ**：「1年間その状態が続いたら、体か生活がもたない」と思うものが、削れない線です。

🆘 **止まったら**

- 空欄があってもかまいません

## 付録1｜AIを使うときの2つの注意

1. **AIの答えをそのまま採用しない。** 自分の出来事が入っていない言葉は、それらしく見えても、しっくりきません。AIには質問してもらう、言い換えてもらう、だけにします
