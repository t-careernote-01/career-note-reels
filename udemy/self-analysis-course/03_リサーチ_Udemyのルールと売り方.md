# リサーチ：Udemyのルールと売り方（2026-11-01時点）

## 調査の制約
support.udemy.com・teach.udemy.com はこの環境からは開けなかった。以下は検索結果の抜粋から取った。**支払い・規約に関わる判断は、講師管理画面とヘルプセンターで現行の値を必ず確かめること。**

## 1. 有料講座の最低要件
- 動画合計30分以上、レクチャー5本以上、HD画質（Course Quality Checklist https://support.udemy.com/hc/en-us/articles/229604988 ）
- 収録前に「テスト動画」で音声と映像のフィードバックを受けるのが推奨
- 全編AIで作った講座は不可。AIは講師の専門性を補う使い方なら可（https://support.udemy.com/hc/en-us/articles/30999984483607 ）
→ 台本は講師本人の体験・判断を入れる。読み上げ前にタクマさんが自分の言葉に直す前提

## 2. タイトル・ランディングページ
- タイトル60文字以内、サブタイトル120文字以内（重要トピックを3〜4個、上限近くまで使うのが推奨）
- お金の約束（収入など）はタイトル・サブタイトルで禁止。「Udemy」の語も原則禁止
- 説明文は最低200語（英語の語数）。推奨は1,000語以上。他講座の文言の流用は禁止
- 学習目標は最低4つ（推奨4〜6、動詞で書く）。対象者の入力は必須
- ランディングページにクーポンコード・紹介リンクは載せられない

## 3. 価格・クーポン・レビュー
- 価格はグローバル価格マトリクスで決まる。日本円の現在の上限・下限は未確認（管理画面で確認）。前回調査では競合は¥3,600〜¥27,800
- クーポン：Best current price／Custom price／Free: Open（最大10名）／Free: Targeted（最大100名）。有効期間・月の上限は出典で食い違いあり
- 日本などでは、新しい有料講座は公開から14日間Udemyのセールの対象外（スタッフ回答）
- 評価は単純平均ではなく、受講量が多く文章付きのレビューほど重い（https://teach.udemy.com/course-reviews-101/ ）
→ 無料クーポンは人数が少なく、レビュー集めには弱い。自分のYouTube・LINEから講師クーポンURLで送るのが中心。成果物ができた直後にレビューを頼む

## 4. 宣伝のルール
- 自分の他講座・商品の宣伝は「ボーナスレクチャー」（1講座1本、最後に置く、タイトルに「Bonus」）とプロモーションメールの中だけ
- 本編・お知らせ・ランディングページで、有料コンテンツや個人情報を求める先（LINE登録など）へ誘導しない
- 無料・教育目的・登録不要の外部リソースはリンク可
→ **有料note（780円）やLINEへの案内は、ボーナスレクチャー1本にまとめる。LINE登録への誘導が許されるかは policy@udemy.com に事前確認**

## 5. 学習機能
- リソース添付：1ファイル最大1GB、数の上限なし（PDF・Excel可）
- 課題（Assignments）：問題・指示・模範解答を作れる
- 小テスト：品質基準あり
- **AIロールプレイ**：2025年5月開始、日本語対応。講師がAIの役・シナリオ・評価ゴール（1〜5個）を設定。作成はデスクトップのみ。Instructor GenAI Program への参加が条件
- Udemy Business：講師のオプトインが前提。英語講座は評価4.4以上・レビュー25件以上（日本語の基準は未確認）。返金率・更新頻度なども見られる

## 6. 収益分配
- オーガニック（Udemy内からの購入）37%／講師クーポン・紹介リンク経由97%
- Udemy Business等のサブスクは2026年1月から15%（受講時間で配分）
- Coursera による Udemy の統合が2026年5月に完了。分配率の変更予定は「現時点でない」と発表
→ **自分のYouTube・LINE・noteから講師クーポンで送ると取り分が大きい。外からの導線が収益の中心**

## 7. 完了率・離脱
- Udemyの公式な平均完了率は公表されていない。講座ごとの差が大きい
- edXの約690万回の視聴の分析で、視聴時間の中央値は動画の長さにかかわらず最大約6分（Guo, Kim & Rubin 2014）。顔とスライドを交互に見せるほうが引き込みが高い
- Udemyスタッフの推奨は1本2〜6分、長くても10分以下、1本1概念
→ 1レクチャー6分前後を基本にする。最初のセクションで小さな成果物を作らせる

## 8. ランディングページの書き方
- 誰の悩みか（対象者を5つ以上）→ 受講後にできること → 進め方 → 講師、の順
- 誇張しない。学べることを正確に書く
