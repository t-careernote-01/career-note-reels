# 配布資料（受講者へのプレゼント）

Udemy講座「自己分析ワーク」の受講者に、レクチャーの「リソース」として渡す資料です。

| ファイル | 中身 | 付けるレクチャー |
|---|---|---|
| 自己分析ワークブック.pdf | 印刷用のワークブック（A4・28ページ）。表紙、使い方、8日間の日程表、ワーク0〜7、記入例3人分、止まったら欄、AIプロンプト、付録1〜7 | 1-3 |
| 自己分析ワークブック_書き込み用.xlsx | パソコンで書き込む版（Excel・Googleスプレッドシートで開ける）。ワークごとのシートに書くと、「1枚まとめ」シートに答えが自動で写る | 1-3 |
| 自己分析ワークブック_テキスト版.txt | スマホのメモに貼って使う版 | 1-3 |
| 自分に合う働き方シート（1枚）.pdf | 5つの枠・1文・今の仕事の点検・今週の一歩を1枚にまとめた印刷用シート | 7-1 |

## 作り直すとき
ワークブックの中身は `../20_ワークブック.md` が元です。原稿を直したら、`_作成スクリプト/` のスクリプトで作り直せます。
- PDF・テキスト版：`python3 build_workbook.py ../../20_ワークブック.md 出力フォルダ` → `node topdf.js 出力フォルダ/workbook.html 出力.pdf`（Playwrightが必要）
- スプレッドシート：`python3 build_xlsx.py 出力.xlsx`（記入例は原稿から手で写しているので、原稿の記入例を変えたらスクリプトも直す）
- 1枚シート：`onesheet.html` を `topdf.js` でPDFにする（ページ番号なし）

## 確認したこと
- PDFはA4で、日本語フォント（Noto Sans JP / Noto Serif JP）を埋め込み済み
- スプレッドシートの「1枚まとめ」は、値を入れて再計算し、元のシートの答えが写ることを確かめた
- 1枚シートはA4で1ページに収まる
