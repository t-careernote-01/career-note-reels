# チェック記録（2026-11-01）

## 進め方
1. リサーチ3本（挫折の声・競合講座・Udemyのルール）＋前のチャットからの引き継ぎ
2. 設計書・ワークブック・台本ルール・台本（全25本）・講座ページを作成
3. 機械チェック（Udemy台本チェッカー：50字超の文・禁止表現・書き言葉・決まり文句）
4. 自分で全文を通読して食い違いを修正
5. 別の担当によるレビューを3回（毎回、作り手ではない立場で）
   - 1回目：購入者目線（架空の受講者3人になりきって受講）＋マーケティング目線
   - 2回目：第2稿の総合レビュー（購入者・マーケティング）
6. 指摘を反映して第3稿

## 主な指摘と対応

### 第1稿 → 第2稿
| 指摘 | 対応 |
|---|---|
| ★だけで進むと「苦手を細かく分ける」が抜ける | 1-Bの★を「もし1つだけ変えられたら、何を変える？」の1問にした |
| 「半年で辞めたくなるか」の判定が、長く耐えてきた人・今つらい人で機能しない | 「もう一度選び直せるなら選ぶか」「人や職場が変わったら平気か」の2問に変えた |
| つらい記憶がある人の道がない | 「イヤだったことを書くのがつらい人へ」の進め方と、相談先（こころの耳など）を追加 |
| 3つの道の基準に穴がある・外を調べる方法がない | 基準を書き直し、「辞めたくない人はA・Bから」を明記。1文を使って職場を見る表（付録4）を追加 |
| AIプロンプトに終わりの条件がない・言い換え用がない | 全プロンプトに「〇問で終わり」を入れ、言い換え用を追加 |
| 時間の見積もりが実際より短い | 8日間の日程表（動画の時間込み、1日20〜30分）を追加 |
| 型と記入例が台本とワークブックで違う | 1文の型と3人の記入例を全ファイルで統一 |
| 毎回の案内が長い・記入例の読み上げが長い | 画面に「ワークカード」を出し、読み上げは3〜4行に |
| 講座ページ：完成例がない・言い切りすぎ・検索の言葉が足りない | 完成例の1文を載せ、「選ぶだけで」などを修正。「キャリア自律」を入れた |
| プレビューの冒頭が自己紹介 | 1-1を完成した1文から始めた。1-2の4つ目を「いきなり強みから考える」に。1-3も無料プレビューに |
| レビュー依頼の位置と言い方 | 1文ができた直後の7-2に移し、「星の数は正直なもので」に |
| 有料noteとの関係 | 講座からnoteへは案内しない。noteから講座へ講師クーポンで送る案を設計書に |
| 記入例が事務・営業・販売だけ | 仕事別の言葉のヒント（IT・介護・医療・接客・製造・事務）を付録5に |
| AIロールプレイの相手が「先輩」 | 先輩との関係がつらい人に配慮し、同年代の社外の友人に |

### 第2稿 → 第3稿
| 指摘 | 対応 |
|---|---|
| つらい人の進め方だと、最後の完成チェックが通らない | 完成チェックを「避けたいこと（苦手）か守りたいこと（生活の土台）が1つ以上」に。苦手が空の人の1文の型を追加 |
| つらい人の進め方で、1-B・1-C・2-Aの扱いが書いていない | 各ステップに「つらい人は〜」を追加。2-Bの止まったら欄の矛盾も解消 |
| ロールプレイの質問がつらい場面を思い出させる | 質問と評価ゴールを変更 |
| 求人票の扱いがチャンネルの方針（転職活動の手順は扱わない）と食い違う | 記入例・付録4・台本・小テストから求人票の読み方に当たる部分を外した |
| 宣伝動画で架空の記入例を実例のように見せている | 画面に「記入例・架空の人物」を出し、最初の一言で記入例だと言う |
| 講座ページの「一覧集・AIプロンプト集」がワークブックにない | 付録6（一覧集の索引）・付録7（AIプロンプト集の索引）を追加し、表記を実態に合わせた |
| 1-Bの★の記入例がない／4-Cが★ではない4-Bを前提にしている／4-Cに止まったら欄がない | 記入例・手順・止まったら欄・AIプロンプトを追加 |
| アヤさんの記入例の時系列が合わない | ワーク0の②を変更 |
| 時間の表記の食い違い | 「★だけなら1シート5〜15分」「休日なら★だけで2時間半〜3時間」にそろえた |
| タイトルが「やりたいこと」が見つかると期待させる | 「やりたいことより先に『合う働き方』を1文に」に変更 |
| 診断の結果の使い道が弱い | 付録2に記入例と使い道を追加。講座ページにも記載 |
